## 왜 만드는가

처음 계획은 업타임 모니터 앱을 쿠버네티스에 올리는 것이었다. 2026년 10월에 그 계획을 버렸다. 모니터링 앱은 쿠버네티스를 쓸 이유와 "왜 이 앱이냐"에 답하지 못했고, 실사용에서 문제를 발견할 수 없었다.

대신 매일 쓰는 개인 도구들을 테넌트로 둔 LLM 게이트웨이를 만든다. 출발점은 실제로 있는 필요 두 가지다. 토큰 비용, 그리고 놀고 있는 맥미니. 업타임 체커는 버리지 않고 이 플랫폼을 바깥에서 재는 외부 프로브로 남긴다.

끝났다고 말할 수 있는 상태는 이렇다. 도구들이 각자 LLM을 직접 부르지 않고 게이트웨이에 작업을 맡긴다. 게이트웨이는 테넌트와 작업 유형에 따라 로컬 모델, Claude 구독, Codex 구독 중 하나로 보내고, 테넌트별 사용량, 지연, 실패를 기록한다. 맥미니가 꺼지거나 구독 한도에 걸려도 정해진 폴백대로 동작하고, 그 과정이 런북과 포스트모템으로 남아 있다.

## 게이트웨이가 하는 일

- **모델 매핑과 라우팅.** 테넌트와 작업 유형마다 맞는 백엔드를 정한다. 가벼운 분류와 요약은 로컬 모델, 품질이 중요한 초안은 구독 모델로 보낸다.
- **아끼는 것은 돈보다 한도.** 구독 요금제를 쓰므로 절감 대상은 구독 한도다. 가벼운 작업을 로컬로 돌려 5시간, 주간 한도를 아끼고 유료 API를 피한다. 이 한도는 내가 직접 쓰는 코딩 에이전트 세션과 공유하므로, 배치 작업이 내 작업 시간의 한도를 먹지 않게 하는 것도 목적이다.
- **할당량과 우선순위.** 테넌트별 한도를 두고, 대화형 요청을 배치 분석보다 앞에 세운다.
- **폴백과 차단.** 백엔드가 죽거나 한도에 걸리면 정책대로 다른 백엔드로 넘기거나 대기시킨다.
- **사용량 기록.** 테넌트별 호출 수, 입력 크기, 지연, 백엔드, 성공과 실패를 남긴다. 라우팅 정책을 바꿀 근거가 된다.

| 테넌트 | 작업 성격 | 처음 세운 라우팅 가설 |
|---|---|---|
| 대화형 비서 | 지연에 민감, 하루 몇 번 | 채팅은 구독, 정기 브리핑 일부는 로컬 |
| 활동 기록 분석 | 배치, 무겁고 몰림, 시간 초과 이력 | 1차 분류는 로컬, 판정은 구독 |
| 공고 문서 구조화 | 드묾, 입력이 큼 | 구독 |
| 문서 작성 보조 | 드묾, 품질 중요 | 구독 |

## 구조

{{< svg "architecture.svg" >}}

M1과 M2에서는 컨트롤 플레인을 맥미니의 kind 클러스터에 두고, 러너와 구독 자격증명은 클러스터 밖 맥미니 호스트에 둔다. M3에서 컨트롤 플레인만 클라우드(Hetzner k3s, Terraform)로 옮긴다. 러너는 바깥의 큐에서 작업을 가져오는(pull) 방식이라 집 네트워크로 들어오는 포트를 열지 않는다. self-hosted CI 러너와 같은 패턴이다.

로컬 모델은 맥미니(M4, 24GB)에서 Ollama로 네이티브 실행한다. macOS의 컨테이너 안에서는 GPU를 쓰기 어렵기 때문이다. 이 판단은 M1에서 실측으로 다시 확인한다. 게이트웨이와 러너는 Go로 쓴다.

## 약관이 정한 설계 제약

구독 요금제를 자동화에 쓰는 것이 이 설계의 전제라서, 2026년 10월 22일에 Anthropic과 OpenAI의 약관과 문서를 먼저 확인했다.

| 제약 | 근거 | 설계 반영 |
|---|---|---|
| 구독 headless 실행은 개인 사용에 한해 허용 | Claude 도움말: `claude -p`와 Agent SDK를 구독 한도로 사용 가능. Codex 인증 문서: access token은 신뢰된 스크립트, 스케줄러, 사설 러너용 | 테넌트는 전부 내 앱, 사용자는 나 한 명 |
| 구독 자격증명을 다른 도구가 수집, 저장, 중계 금지. 바이너리 수정 금지 | Claude Code Legal and compliance | 토큰을 꺼내 API를 직접 부르지 않는다. 러너는 수정하지 않은 CLI를 작업 단위로 실행한다 |
| 자격증명 공유 금지, 타인 대행 금지 | Anthropic 소비자 약관, OpenAI 약관 "Registration" | 다른 사람이 쓰게 되면 API 키 경로로 전환한다 |
| 한도 우회 금지 | OpenAI 약관 "circumvent any rate limits" | 계정 여러 개를 돌려 쓰지 않는다. 한도에 걸리면 대기하거나 로컬로 폴백한다 |
| 공개되거나 신뢰할 수 없는 환경에 Codex 실행 노출 금지 | Codex 인증 문서 | 구독 자격증명과 러너는 맥미니에만 둔다. 클라우드 노드에는 두지 않는다 |
| 회사 정보 경계 | 개인 원칙 | 회사 원천의 본문은 클라우드 컨트롤 플레인에 올리지 않는다. 큐에는 작업 참조만 두는 방식을 M3에서 정한다 |

OpenAI 약관의 "Automatically or programmatically extract data or Output" 금지는 화면 스크래핑 같은 우회 수집을 가리키는 것으로 해석했다. 공식 `codex exec`는 OpenAI가 문서로 제공하는 자동화 경로다. 해석이 바뀌면 Codex 러너를 API 키 경로로 바꾼다.
